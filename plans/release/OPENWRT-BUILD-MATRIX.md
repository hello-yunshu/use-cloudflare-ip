# OpenWrt build matrix

Required package targets are OpenWrt 24.10.x IPK x86_64 and 25.12.x APK x86_64 using the actual available stable SDK tags. Every SDK Prepare, Build and Inspect step runs with `/builder` as its working directory. Inspection must find the binary, all modules, RPC/init/ACL/menu, full CSS/JS, UCI conffiles and LMO assets.

Development uses `PKG_VERSION:=2.1.1-dev`; the release candidate and `main` use exact `PKG_VERSION:=2.1.1`. The APK job changes only the checked-out package Makefile to numeric `2.1.1.1` when building a development ref because the 25.12 SDK rejects the source development suffix; it does not use a global Make variable, so dependency versions remain untouched. The IPK job uses the source value. IPK artifacts are validated with `tar -tf`; APK v3 artifacts are structurally validated with the SDK's database-independent `apk adbdump`, because APK v3 ADB files are not tar archives. The matrix includes 24.10.5/24.10.8 IPK and 25.12.0/25.12.5 APK x86_64 targets.

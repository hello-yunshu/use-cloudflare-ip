# Release gates

Development version is `2.1.1-dev`; the `release/2.1.1` candidate and `main` use exact `2.1.1`. `QUALIFICATION_COMPLETE` can be generated only when all legacy items, host/legacy/RPC-LuCI/generic-Rill consumer jobs, OpenWrt 24.10.5/24.10.8 IPK, OpenWrt 25.12.0/25.12.5 APK, behavior rollback gates, release-asset contract, evidence manifest and real CFST smoke are green. The generic Runtime package has its own exact-commit Stable and Preview IPK/APK qualification evidence in `rill-openwrt-packages`; consumer integration must execute the extracted `rill-runtime-preview` artifact, with matching package and upstream commits. The generated `qualification.json` binds the result to the exact commit and run ID. Release promotion is triggered only from a successful CI `workflow_run` on `main` and rechecks that same SHA/evidence manifest before publishing `v2.1.1-1`. Device/hardware evidence is separate and cannot be inferred from Docker or package builds.

# Release gates

Development version is `2.0.0-dev`; no stable tag is allowed on development branches. `QUALIFICATION_COMPLETE` can be generated only when all legacy items, host/legacy/RPC-LuCI/generic-Rill consumer jobs, OpenWrt 24.10.5 IPK, OpenWrt 25.12.0 APK, behavior rollback gates, release-asset contract, and real CFST smoke are green. The generic Runtime package has its own exact-commit IPK/APK qualification evidence in `rill-openwrt-packages`. The generated `qualification.json` binds the result to the exact commit and run ID. Release promotion is triggered only from a successful CI `workflow_run` on `main` and rechecks that same SHA/evidence manifest. Device/hardware evidence is separate and cannot be inferred from Docker or package builds.

# Cloudflare IP 2.2 Adaptive Measurement

2.2 adds an optional Native adaptive measurement layer. It is separate from
the Candidate-only Rill Preview integration and does not add another Runtime
learner or partition.

The shipped default is Shadow: production continues to use the existing
Native order while complete full audits compare the baseline, CFST, and
adaptive schedules. Guarded mode is available only after fresh, compatible
evidence meets the documented recall, safety, and savings thresholds. A
qualification downgrade, missing audit, invalid state, or probe error causes
the next run to use the complete Native baseline.

The adaptive-status RPC and the Intelligence page show the effective mode,
qualification state, audit count/freshness, selected K, expansion/fallback,
and scheduler/contract versions. These are diagnostics, not a claim of
hardware, physical OpenWrt, or 24-hour soak validation.
